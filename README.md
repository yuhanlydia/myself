# Myself · 你的成长助手

私人中文聊天网站：https://myself-daily.longyunbo218.chatgpt.site

## 使用

1. 打开网站，点击「认识我」填写昵称、生活角色、目标和可安排时间。
2. 使用当前 ChatGPT：在 ChatGPT 桌面端内置浏览器打开本站并登录，保持页面打开，在旁边的 ChatGPT 对话中要求读取档案、安排任务或保存记录。具体支持范围见下方说明。网站聊天框不会自动把消息发给 ChatGPT。
3. 「今日打卡」记录心情、精力、睡眠、活动与日记。
4. 相机按钮上传私人照片；每次勾选后，照片才会随该条消息发送给 AI。
5. 「成长记录」管理日记、照片、确认过的长期记忆和公开作品动态。
6. 「连接账号」输入 GitHub / Hugging Face 用户名，手动读取公开动态。
7. 「我的数据」导出文字数据或删除所有网站数据。照片可逐张下载。

## 当前状态

- 档案、任务、日记、记忆：Cloudflare D1 持久化，所有查询按平台用户 ID 隔离。
- 照片：私有 R2，通过受认证 API 读取；客户端缩小到最长边 1600px 并重编码，移除原 EXIF。
- 当前 ChatGPT：页面通过 WebMCP 提供 8 个真实读写工具，使用当前登录用户的受保护 API，不调用模型 API、不需要本站配置密钥。普通浏览器和 ChatGPT 网页端不能通过此入口调用。
- 网站内独立 AI：服务端 Responses API + 图像输入 + JSON Schema，需配置 `OPENAI_API_KEY`；没有密钥时仅保存消息，并引导回到 ChatGPT 对话。
- `OPENAI_MODEL` 可选，默认 `gpt-4.1-mini`。密钥只能设置为 Sites 运行时 secret，不能加入仓库或客户端。
- GitHub / Hugging Face：用户点击时读取公开活动与作品，无私有账号授权，无后台自动同步。
- Outlook / X：尚未配置网站 OAuth/API，界面明确标为未授权。ChatGPT 的连接不会自动继承到网站。
- 网页无法监听 Mac 键盘、其他应用、手表数据；无后台提醒或医疗诊断功能。

## 隐私与记忆

网站保持仅所有者可访问。数据保存在云端，并非仅在设备上或端到端加密。平台入口提供认证头，后端逐个检查，不接受客户端自报的 owner。

网站内独立模型 API 使用资料需档案中明确同意；每次看照片另行选择。网页工具由 ChatGPT 按用户请求调用，仅返回请求的记录分区，不包含照片原文件、存储路径或模型 API 同意字段；用户自行决定是否将这些内容交给 ChatGPT。AI 仅提出候选长期记忆，用户确认才保存。长期记忆可编辑、删除。每次请求仅选取近期对话、任务、打卡、公开活动和有限条长期记忆；历史原始记录保留到用户主动删除。目前没有实现语义检索、自动遗忘或声称无损压缩。

删除图片会清理存储对象及消息引用。表单使用版本号，避免两个页面相互覆盖。AI 提议的固定时间若与原安排冲突，改为灵活任务，最终以任务侧栏时间为准。无空档的任务显示等待安排。

## 开发与验证

Node >= 22.13，pnpm 11。

```sh
pnpm install
pnpm db:generate # 仅变更 schema 时；已发布 migration 不修改
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

项目基于 Vinext、React、Shadcn UI，部署为 Cloudflare Worker。Sites 清单声明逻辑绑定 `DB` 和 `BUCKET`。不能将网站直接当作 GitHub Pages 静态文件部署。

测试包括排程、输入校验、实际路由的 SQLite 持久化、账号隔离、冲突更新、照片删除、AI 同意与未配置行为。模型测试使用模拟响应验证处理逻辑，不表示已完成真实模型 API 连通测试。没有配置密钥前，真实 AI 测试和授权同步测试不可用。

旧版 `myself.workspace.v1` 本地数据只在用户明确点击「导入旧版记录」后上传，原本地副本保留；不会导入示例数据。

## 用当前 ChatGPT（网页工具）

1. 更新 ChatGPT 桌面端，在内置浏览器打开本站并登录。
2. 使用支持 Site tools 的模型，检查地址栏的 Site tools。官方当前列出 GPT-5.6 Sol / GPT-6 Sol；Enterprise / Edu 暂不支持，实际可用性受开放范围影响。
3. 回到 ChatGPT Work 对话，说「读取 Myself 的档案，帮我安排明天，并保存到任务」。
4. 保存会更新网站。说「把这段对话保存到 Myself」可保存选定的一组问答，不会自动复制整个聊天记录。照片请直接发给 ChatGPT；照片文件不会自动转存本站。

[官方网页工具说明](https://learn.chatgpt.com/docs/webmcp)

| 工具 | 行为 |
| --- | --- |
| `myself_read_context` | 选择读取档案、任务、记忆、打卡、消息或公开活动，按分区限量 |
| `myself_update_profile` | 保存用户明确提供的资料，保留原有模型 API 同意状态 |
| `myself_save_memory` | 保存用户要求记住的事实、偏好或体会 |
| `myself_save_checkin` | 保存用户自述的每日打卡，不猜测健康数据 |
| `myself_create_tasks` | 批量创建 1–8 项任务，保护原有时间安排，重试不重复插入 |
| `myself_set_task_done` | 修改已有任务的完成状态，检查记录版本 |
| `myself_save_exchange` | 保存用户指定的一组真实问答，重试不覆盖已有内容 |
| `myself_open_today` | 打开今天的任务侧栏 |

网页工具仅在支持的浏览器中注册，退出页面即失效。界面区分「工具已就绪」和「已经调用」，普通浏览器显示使用说明。好友必须获得网站访问权限，使用自己的登录身份；当前网站仍仅自己可访问。

**安装式 MCP 插件仍未接通。** 原生 Sites 连接接口提示需要声明 MCP，但当前可用文档没有提供受支持的启用与授权配置，因此没有猜测清单配置、开放匿名接口或绕过登录。

验证：工具执行函数已通过真实路由与 SQLite 的集成测试，覆盖账号隔离、版本冲突、任务重试和数据回读。当前执行环境没有支持的 ChatGPT 桌面浏览器，尚未完成真正的 WebMCP 发现与调用验收；网页提供的就绪状态也不代表客户端已经连接或调用成功。
