# Myself

个人时间规划与记忆网站：打开浏览器即可使用。

## 已实现

- 任务的新增、编辑、完成、删除与日期调整。
- 根据固定约定、重要程度、角色优先级和可用时段自动安排时间；显示冲突与放不下的任务。
- 专注计时、暂停、继续与完成反馈。
- 事实、偏好和想法的记录、编辑、删除及搜索。
- 工作、关系、健康、自我四个角色的时间分配与优先程度。
- 当前浏览器的数据保存、JSON 备份导出与恢复。
- 桌面与移动端布局、键盘搜索和可关闭的示例内容。

## 使用边界

这是可交互的网页版第一版，排程使用可解释的规则，尚未接入大模型。记忆由用户添加；尚未自动采集 Mac 窗口、网页、键盘、聊天记录，也未接入日历或手表。

当前采用设备本地的数据模式：记录保存在当前浏览器的 localStorage，不上传到网站服务端，不跨设备同步。浏览器清理网站数据可能删除记录；备份是未加密的 JSON，请妥善保管。其他能使用该浏览器的人也可能读取本地记录。

专注计时以时间戳计算，恢复页面时会更新剩余时间；页面关闭后不会发送系统通知。完成计时不会自动把任务标记为已完成。

首次打开为明确标注的合成示例。开始使用时可清空示例。

## 源码

- `dist/index.html`：页面与表单。
- `dist/styles.css`：布局、视觉样式和响应式适配。
- `dist/core.mjs`：任务校验、排程与备份格式校验。
- `dist/app.js`：页面交互、本地保存、记忆管理和计时。
- `tests/core.test.mjs`：排程冲突、时间边界、导入校验等测试。

没有构建依赖，部署 `dist/` 即可。通过 HTTP 静态服务器访问，不要直接用 `file://` 打开 ES module。

```bash
python3 -m http.server 8000 --directory dist
```

校验：

```bash
npm run check
npm test
```

本版本按用户纠正，交付网站；之前的 Mac 客户端设计 PR 已被网站方向取代。网站界面仍可在未来接入独立的本地采集模块。
